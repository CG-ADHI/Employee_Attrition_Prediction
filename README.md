# Employee Attrition Prediction for HR

## Overview

This project predicts employee attrition using Machine Learning techniques. It helps HR departments identify employees who are likely to leave the organization, enabling proactive retention strategies.

---

## Objectives

- Predict employee attrition
- Perform Exploratory Data Analysis (EDA)
- Compare Machine Learning models
- Identify important factors influencing attrition
- Generate HR insights

---

## Dataset

IBM HR Analytics Employee Attrition Dataset

- Employees: 1470
- Original Features: 35

Target Variable:

- Attrition
    - Yes
    - No
